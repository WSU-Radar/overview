• Production runs on KNPHI/DHA-approved or other Government-authorised infrastructure; the budgeted Dell PowerEdge R770 is the project's main server; development uses non-identifiable data only.
  • The network is split into zones with a few allowed paths; the AI zone has no internet egress.
  • Controls follow the proposal's list — RBAC, least privilege, MFA, encryption, audit logging, backup/recovery and incident response — mapped to recognised standards.
  • Before production: load, penetration and interface testing with reports shared with the foundation (Gate 2).

RADAR concentrates sensitive signals from many institutions and sits in the escalation path for emergencies. A breach would damage trust in every connected system; an outage during an outbreak would push EOCs back to paper exactly when speed matters. Security and resilience are therefore gate criteria, not afterthoughts.

Pre-production checklist (Gate 2)

The stage gates require product hardening with test reports available to the foundation: scalability and load testing, cybersecurity and penetration testing, interface validation, and deployment within KNPHI/DHA-approved infrastructure. Proposal

  1. Load test at 10× normal volume (simulated national outbreak week) with workspace response times measured.
  2. Penetration test by an independent party covering web app, APIs, gateway and MCP tools; findings fixed and re-tested.
  3. Interface validation for every connector and the GHEC-AI hand-off, with signed test records.
  4. Restore test from off-site backup into a clean environment, timed against RTO.
  5. Access review confirming every account, role and break-glass path.
  6. Runbooks for operations, incidents and upgrades handed to KNPHI ICT.

Operations

  • Monitoring: pipeline freshness per source, error rates, queue depth, GPU/CPU/disk, certificate expiry, failed logins — alerts to an on-call rota.
  • Patching: monthly for OS and dependencies; emergency patches within 72 hours for critical vulnerabilities.
  • Change management: all changes via CI/CD; production changes approved by the KNPHI system owner.
  • Transition: by Gate 3 the system runs on Government infrastructure with administrative rights transferred and maintenance, support and security procedures handed over. Proposal
